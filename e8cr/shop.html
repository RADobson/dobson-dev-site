Questions

Why is the hardware so cheap?

We sell hardware at our cost + 5%. We're not a hardware company — we make money on the subscription service that makes the hardware useful. This means you're never overpaying for the box.

Can I use my own hardware instead?

Yes. If you already have a Mac Mini, spare PC, or server — we can deploy E8CR agents on it. You just pay the subscription. Hardware specs: minimum 16GB RAM, 256GB storage, Gigabit Ethernet.

Does any data leave my network?

No. The E8CR agents run entirely on-prem. AI inference runs locally on the device. Your vulnerability scans, MFA status, patch data, and compliance reports never leave your building. Zero cloud dependencies.

What Microsoft licensing do I need?

Microsoft 365 Business Premium, E3, or E5. The agents connect via Microsoft Graph API using a service account with read permissions (and write for remediation, if you opt in).

How long does setup take?

Hardware ships within 5 business days. Once you plug it in and grant Graph API access, the agents start their first compliance scan within hours. First full report within 24 hours.

What if I want to cancel?

Cancel the subscription anytime — no lock-in, no exit fees. The hardware is yours to keep. We'll help you gracefully decommission the agents.

I'm an MSP — can I resell this to my clients?

Yes. We have a partner program with wholesale pricing. You white-label the reports, set your own client pricing, and we handle the tech backend. Get in touch.
