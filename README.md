# Dobson Development

The website for Dobson Development Pty Ltd: Claude, Apple and Proton for Australian business.

Live at https://dobsondevelopment.com.au

One static page, `index.html`, with its styles inline. GitHub Pages serves it as is; pushing to `main` publishes. The previous multi-page site is in the git history.

The logo is the `dobson_dev_` wordmark with a cyan-to-violet cursor. Vector files are in `assets/brand/`. Typeface: Geist (SIL OFL), self-hosted in `assets/fonts/`.
